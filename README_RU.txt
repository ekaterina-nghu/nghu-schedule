НГХУ v2.9 — локальная работа + облачная синхронизация

1) Без интернета приложение работает локально после первого запуска.
2) Для синхронизации двух устройств нужен один HTTPS-адрес API. В поле «Адрес облачного API» укажите адрес опубликованного cloud-server.js.
3) На обоих устройствах одинаковые: адрес API, код рабочей области и ключ синхронизации.
4) Нажмите «Сохранить» → «Сохранить в облако» на устройстве-источнике, затем «Загрузить» на другом устройстве.
5) VPN для синхронизации не нужен, если API доступен напрямую из вашей сети.
6) Для публикации cloud-server.js нужен любой Node.js-хостинг с постоянным хранением файла ng​hu_cloud_state.json. Для production лучше заменить файловое хранилище на БД.

Внимание: ключ синхронизации должен быть секретным. Не отправляйте его в общий доступ.
